UMBREL HOST HOOKS

Umbrel custom-hooks manager

Install the managed host hooks, edit .smbcredentials, and only mount the NAS shares after you have replaced every CHANGE_ME.

This app also watches for manual restarts of the Gluetun container and will stop dependent apps first, then bring them back after Gluetun is healthy again.

What Happens Next

  1. Install this app from your Umbrel store.
  2. Open this page and replace all CHANGE_ME values.
  3. Save the credentials file.
  4. Wait a few seconds while the host watcher reruns the managed pre-start and mounts the shares automatically.
